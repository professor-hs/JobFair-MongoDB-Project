# JobFair Nexus — Online Job Fair & Recruitment Management System

A full-stack campus placement and job fair management system built with **HTML5, CSS3, Bootstrap 5, jQuery, Node.js, Express, MongoDB**, and integrated with **Live Public REST APIs** for instant cloud & static deployment on **Netlify**.

## 🔐 Compulsory Starting Login Credentials
- **Admin Login**: `Admin1` / `Admin@1234`
- **Student Logins**: `student1` / `Student@1`, `student2` / `Student@2`, `student3` / `Student@3`, … (`studentN` / `Student@N`)

## ✨ Key Features
- **Interactive Placement Dashboard**: Live KPIs, monthly recruitment activity charts, and candidate pipeline distribution.
- **Live Public APIs Integration Hub**: Remotive API, Arbeitnow API, DummyJSON API, RandomUser.me API, and JSONPlaceholder API.
- **Full CRUD Workflows**: Companies, Job Openings, Students, Applications, Interviews, Reports & CSV Export.
- **Hybrid Storage Architecture**: Works with **Express + MongoDB** locally and **Public APIs + LocalStorage Persistence** on **Netlify**.
